# 进阶版 · 多订阅链式菜单

**不确定选哪种？先用[默认版](../README.md#三步上手)。** 经常切换订阅时，进阶版可在主选择组里用一个「链式代理」菜单切换。

[English](README.en.md)

| 选项 | 前置节点来源 |
| --- | --- |
| 链式代理 A、B、C | 各自指定的订阅 |
| 链式代理 总 | 所有已配置订阅合并选优 |

四个选项复用默认版顶部填写的同一个 SOCKS5 出口。原住宅链路和规则仍来自默认脚本。空位拒绝连接。若订阅已有同名菜单或节点，扩展保留默认版结果，避免覆盖原配置。

1. 下载或克隆仓库。在 Clash Verge Rev 刷新订阅，然后通过订阅卡片的「编辑文件」保存每个订阅的原始 Clash YAML 副本。每份需有顶层 `proxies` 列表。生成器读取节点并跳过不支持的类型及已有 `dialer-proxy` 的节点。
2. 在仓库根目录用 Python 3.8+ 运行。只填实际使用的订阅选项，至少填一份。路径为示例。

   ```sh
   python3 -m pip install PyYAML
   python3 advanced/build.py --a ~/Downloads/sub-a.yaml --b ~/Downloads/sub-b.yaml --c ~/Downloads/sub-c.yaml
   ```

3. 在生成的 `clash-chain-menu.local.js` 顶部填写住宅 SOCKS5 地址、端口、用户名、密码。如果已有填写过的默认版，可以运行生成器时用 `--base` 指向该本地脚本，沿用原设置。备份当前扩展脚本，再把生成的完整脚本粘贴到原位置并保存。
4. 保持规则模式。主选择组选择「链式代理」，再选择需要的 A、B、C 或「总」。逐一用 IP 查询网站核对住宅出口，并在连接列表确认实际代理链。要切回默认版，恢复备份脚本。

进阶版的节点来自本地快照。订阅更新后，重新保存 YAML、运行生成器并替换扩展脚本。A、B、C 和「总」共享各订阅的按需测速，可能增加订阅流量。测速只反映前置可用性，住宅出口仍需单独核验。

导出的 YAML、生成脚本和运行配置含代理凭据，请留在本机。生成器无需订阅 URL 或 Portal 登录密码。普通 SOCKS5 用户名密码认证未加密，请使用可信前置节点。
